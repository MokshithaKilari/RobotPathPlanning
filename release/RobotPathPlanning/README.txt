INTELLIGENT ROBOT PATH PLANNING AND DYNAMIC OBSTACLE AVOIDANCE SYSTEM
========================================================================

HOW TO RUN:
  Double-click RobotPathPlanning.exe in the packaged release folder.
  Keep the assets/ folder, scenarios/ folder, and DLL files in the same
  directory as RobotPathPlanning.exe.

CAPSTONE VIVA DEMONSTRATION FLOW:
  1. Click "Presentation" in the top navigation bar.
  2. Click "1. Initial Route" to compute and display the A* path.
  3. Click "3. Run / Resume" to start smooth robot navigation.
  4. Click "2. Block Path" (or click directly on the violet path) to place
     an obstacle mid-navigation and trigger automatic A* replanning.
  5. Open "Scenario Manager" -> Scenario 4 or 5 to demonstrate autonomous
     moving dynamic obstacles and real-time collision avoidance.
  6. Open "Analytics" and "Explain A*" tabs to inspect node-by-node G/H/F
     math, A* vs Dijkstra efficiency, and recorded telemetry charts.
